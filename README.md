# IDX

[![Latest release](https://img.shields.io/github/v/release/emberyard/idx-releases?label=latest)](../../releases/latest)
&nbsp;macOS, Apple Silicon

**A Mac cockpit for running Claude Code and Gemini CLI across many projects.** One window per project, chat and
terminal side by side, sub-agents and long output one click from full size, and you choose the account every time.
IDX runs on top of your own agent CLIs and accounts; it does not replace them.

[Product page](https://emberyard.github.io/idx-site/) for screenshots and what is inside.

## Download

Get the `.dmg` from the [latest release](../../releases/latest), open it and drag IDX to Applications.

- Requires a Mac with Apple silicon.
- Builds are signed with a Developer ID and notarized by Apple.
- You need your own [Claude Code](https://code.claude.com/docs/en/overview) installed and signed in. Gemini CLI is
  optional.

## Updates

IDX updates itself. When a new version is ready, a button appears in the title bar with the headlines of that version.
Nothing restarts until you press **Restart**; your chats and windows come back afterwards. The full list for every
version is on the [releases page](../../releases) and in the app under Help, What's New.

## About this repository

This repository only serves the downloads and the update feed that the app checks. Please do not edit or delete the
release files: installed copies of IDX read them. It is a private beta, and "IDX" is a working name.
